# わくわく洗濯機ラボ ＋ わくわく扇風機ラボ

子どもがドラム式洗濯乾燥機を自分の手で動かし、外装を透かして中の部品を観察し、さらに布の繊維の世界まで潜って「なぜ汚れが落ちるのか」を体験する 3D Web アプリです。

React + TypeScript + Three.js + React Three Fiber + Drei + Vite。外部の有料 API や音声ファイルは使っていません（効果音は Web Audio で合成）。

## 動かし方

```bash
npm install
npm run dev
```

本番ビルドは `npm run build`（`dist/` に出力）。Vercel ではリポジトリをインポートするだけで `vercel.json` の設定（Vite / `dist`）で公開できます。

## 体験の流れ

1. 「とびらを あける」（扉をタップしても開きます）
2. 服を選ぶ（シャツ・くつした・タオル・ズボン・くまちゃん）
3. 「いれる」で洗濯槽へ。全部入れたら「しめる」
4. 「せんざいを いれる」（または「みずだけ」）
5. コースを選ぶ（おまかせ／はやい／しっかり／かんそうつき、いずれも約 1〜2 分）
6. 「スタート」。給水 → 洗い → 排水 → すすぎ → 脱水（→ 乾燥）が連続して進みます
7. 終わると虹色のシャボン玉とメロディ。「とりだす」で服がふわっと現れ、「もういっかい」で最初から

運転中は「ゆっくり」（0.3 倍速）と「とめる」で、工程をひとつずつ観察できます。

## 見どころ

- **はじめの画面**：「せんたく する／たんけん する／じっけん する」から遊び方を選びます。左上のタイトルを押すといつでも戻れます。最初のタップで音と読み上げが有効になります。
- **読み上げ**：工程の切り替わり、部品の解説、繊維の世界、たんけんの説明を端末の読み上げ機能で声でも伝えます（音を消すと止まります）。

- **なかをみる**：外装が徐々に透明になり、回転ドラム・外槽・ダイレクトドライブモーター・給水弁と給水経路・排水ポンプと排水経路・ダンパーとばね・乾燥ユニット・洗剤投入口を観察できます。名札や下のチップをタップすると、カメラがその部品へ寄って光り、短い解説が出ます。配管は半透明で、中を流れる水（排水は汚れ具合で色が変わる）が見えます。
- **もっとちかく／服をタップ**：カメラが布へ連続的にズームし、「繊維の世界」へ。水がしみこみ、洗剤の粒（青いあたま＝みずがすき、オレンジのしっぽ＝あぶらがすき）が油汚れを囲み、撹拌で運ばれていく様子を、7 つの場面で見せます。洗剤なしで洗った場合は、油が水をはじいて残る別の展開になります。
- **たんけん**：ボタンひとつで「みずの つぶの だいぼうけん」へ。案内役のしずくと一緒に、給水弁 → 水の通り道 → 洗剤投入口 → 外槽 → ドラムでの洗い → 排水ポンプ → 排水ホース → 脱水 → 乾燥の風の通り道 → ゴールまで、10 の章で洗濯機の中を旅します。章ごとに機械が実際に動き、説明は読み上げ付き。「まえ／つぎ／とめる／ゆっくり」で自分のペースでも進められます。たんけん中は本物の洗濯はひと休みし、終わると元の状態に戻ります。
- **じっけん**：4 つのミニ洗濯機で「洗剤あり／なし」「回す／回さない」「時間 短い／長い」を自由に組み合わせて比べられます。

## 教育モデルについて

- 洗濯工程・構造は、代表的なドラム式洗濯乾燥機（ダイレクトドライブ、ヒートポンプ式乾燥）を簡略化したものです。実機では機種によって工程や部品配置が異なります。
- 水や布は流体計算・布シミュレーションではなく、軽量な疑似シミュレーションです（ドラム断面での質点運動＋頂点シェーダーでの布の変形）。
- 脱水の回転数表示は実機に近い値（最高 1000 回/分）ですが、画面のドラムは見やすい速さに抑えています。
- 繊維の世界は科学的な模式図で、実際の分子の大きさや形を再現したものではありません。
- 実験モードの結果は原理を理解するための教育モデルで、洗浄性能の予測ではありません。

## 技術メモ

- `src/sim.ts`：洗濯サイクルの状態機械（水位・回転・泡・汚れ・湿り気・温度など）
- `src/clothSim.ts`：衣服の近似物理（重力・浮力・ドラム壁＋リフターによる持ち上げ・衣服同士の押し合い）
- `src/clothMaterial.ts`：布の形を SDF で切り抜き、曲げ・はためき・しわ・汚れ・濡れを 1 つのシェーダーで表現
- `src/scene/*`：部屋、洗濯機本体、内部機構、水、繊維の世界、実験
- 端末の負荷に応じて `PerformanceMonitor` で解像度と品質（粒子数・分割数）を下げます。かごは `Detailed` による LOD。
- ジオメトリ・マテリアル・テクスチャは共有／`dispose` し、イベントリスナーは解除しています。タブが隠れたら音声を停止します。
- 動作確認用に URL へ `?speed=8` を付けると早送りできます（UI には表示されません）。

## わくわく扇風機ラボ（/fan/）

同じサイトの `/fan/` で開く、扇風機版の体験です。洗濯機ラボの はじめの画面からも行き来できます。

- **かぜを だす**：台のボタン（きる／よわ／ちゅう／つよ）と首振り。羽根の回転数と風の強さが表示され、青い風の粒・かざぐるま・風鈴（音つき）・ガードのリボンが風に反応します。
- **なかをみる**：ガード、羽根、モーター（コイルが順番に光って回る磁石の力を表現）、コンデンサー、首振りの歯車（ウォームギア→大きな歯車→うで）、スイッチ、電気の通り道。
- **たんけん**：「でんきの つぶ」になってコンセント → スイッチ → 支柱 → モーターへ。そこから「かぜの つぶ」に変身して、うしろから吸いこまれ、羽根に押され、首振りの歯車、部屋の小物、汗が乾いて涼しくなる「きみの うで」まで 10 章で旅します。
- **じっけん**：羽根の枚数（3／5／7）、角度（ねかせる／ちょうどいい／たてる）、強さ（よわ／つよ）を変えた 3 台を比べます（教育用のモデルで、実際の性能予測ではありません）。

ソースは `src/fan/` にあり、読み上げ（`src/speech.ts`）、テクスチャ、共通の画面スタイルを洗濯機ラボと共有しています。

## はっけん ずかん（ふたつのラボで共通）

はじめの画面の「📒 はっけん ずかん」から開きます。せんたくを最後までする、なかをのぞく、部品をぜんぶタップする、たんけんを最後まで行く、じっけんで比べる、風鈴を鳴らす……といった発見をすると「シール ゲット！」が出て、ずかんにシールが貼られます（洗濯機 9 まい＋扇風機 7 まい）。まだのシールには「？」とヒントが出ます。

シールはこの端末のブラウザ（localStorage）にだけ保存され、同じサイトなので洗濯機ラボと扇風機ラボで同じずかんを共有します。保存できない環境でも遊びはそのまま続けられます。定義は `src/stamps.ts`、画面は `src/ui/Zukan.tsx`、各ラボの判定は `src/wireStamps.ts` と `src/fan/wireStamps.ts` です。

## ホーム画面・共有

- `public/manifest.webmanifest`（洗濯機）と `public/fan/manifest.webmanifest`（扇風機）、`public/icons/` のアイコンで、スマホの「ホーム画面に追加」からアプリのように開けます。
- `public/og/` のカード画像と OGP タグで、ブログや SNS にリンクを貼ったときに絵つきのカードが出ます（`og:image` は公開 URL の絶対パス）。
- JavaScript を読みこむ前から、HTML だけで「よういちゅう…」の画面が出ます。
